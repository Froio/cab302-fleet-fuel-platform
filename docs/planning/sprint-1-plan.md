# Sprint 1 Plan — Authentication & Vehicle Management

## Sprint goal

> Create the core application structure so a fleet manager can enter the
> application and manage vehicles, with the design ready for persistent SQLite
> storage.

## Sprint scope

Sprint 1 focuses on authentication, the fleet manager dashboard, vehicle CRUD
screens, project structure and initial database design.

Tasks should be moved between Trello workflow columns according to their actual
state rather than being grouped by team member.

## Sprint completion criteria

Sprint 1 is considered complete when:

- the selected Sprint 1 stories have clear acceptance criteria;
- UI designs exist for authentication and vehicle management;
- the JavaFX screens required by the sprint are functional enough to navigate;
- the initial database design has been agreed;
- vehicle data can be persisted or the persistence integration is demonstrably
  underway;
- work is committed to GitHub using identifiable individual commits.
